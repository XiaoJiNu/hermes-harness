# Archived APOSD Chinese Translation

This directory is a durable, version-controlled archive of the local Chinese
translation repository for John Ousterhout's *A Philosophy of Software Design,
2nd Edition*.

## Why this archive exists

The original local checkout used to derive the Hermes skill may be deleted:

`/home/yr/yr/code/cv/object_detection/3D_OD/MV2DFusion-gly/aposd2e-zh`

To keep the source material available on future machines, this archive is
stored inside the `a-philosophy-of-software-design` skill under the canonical
`hermes-harness` repository. Installing the skill from this repository copies
this archive together with the skill.
